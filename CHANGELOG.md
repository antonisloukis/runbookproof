## [0.1.0] - 2026-08-04

### Added

- Static analysis for commands embedded in Markdown documents
- Recursive directory scanning for Markdown files
- Command extraction from fenced code blocks
- Text, JSON, and SARIF 2.1.0 reports
- Stable finding fingerprints and source locations
- Exit codes suitable for CI and automation
- AWS CLI verification pack
- Azure CLI verification pack
- Bash verification pack
- Docker verification pack
- Git verification pack
- Kubernetes verification pack
- Node package-manager verification pack
- Python package-manager verification pack
- Terraform verification pack
- Universal verification pack
- Rule-level ignore controls
- `.runbookproof.toml` configuration support
- Built-in rule catalogue command
- Generated rule reference documentation
- GitHub Code Scanning integration
- Multi-version CI for Python 3.11 through Python 3.14
- Strict Ruff, MyPy, and test-coverage validation
